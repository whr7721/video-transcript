拾文 · 从音频到可读笔记

适用 Windows 10/11 x64。第一次安装需要联网和可用磁盘空间。先解压到自己的固定文件夹，例如 D:\拾文；不要直接在 ZIP 内运行。安装后不要移动文件夹，需要换位置时重新安装。

① 双击安装

解压后双击 install.cmd，等待显示 Installed。它会下载运行环境和本地语音模型，不需要自己安装 Python、ffmpeg 或 Deno，也不需要 Node.js。网络失败时保留窗口提示，恢复网络后再运行即可。

然后双击 start.cmd，浏览器会打开拾文。以后日常使用只需 start.cmd。

下载失败不要关闭系统安全软件或跳过校验；把错误提示交给交付者。文件夹路径含中文可用，但建议放在短路径，不放在系统受保护目录。

② 申请 AI Key：注册 → 充值 → 创建 → 填入拾文

本地转写不需要 Key。生成完整整理稿、精华、金句和导图会调用云端文本模型，需要你自己的账号和余额；处理的文字会发送给硅基流动。

  1. 打开 硅基流动控制台，按提示注册或登录；若平台要求身份核验，按平台要求完成。
  2. 在控制台找到余额/充值页面，先查看模型价格和自己的余额，再自行选择小额充值。充值款付给硅基流动，不包含在拾文安装服务费里；此处不承诺固定最低充值额。
  3. 进入“API 密钥 / API Keys”，新建一个 Key，并复制。不要发给陌生人、放进截图或发布到网上。
  4. 回到拾文，点击设置，找到硅基流动 Key 输入框，粘贴并保存。确认显示“已配置”，再尝试整理。密钥只用于你的模型账号，用 Windows 当前账户加密保存；换电脑需要重新填写。

上图为操作示意，不是平台截图；按钮名称以实际页面为准。参考 硅基流动官方入门。余额、权限、限流或网络问题都可能导致整理失败，原稿会保留。

③ 放入材料

浏览器页面点“新建提取”导入本地音频。RSS 可使用现有播客入口。YouTube 使用随包命令行，不需要启动网页：

.\shiwen.cmd add "C:\录音\访谈.mp3" --summarize
.\shiwen.cmd add "https://www.youtube.com/watch?v=作品ID" --summarize
.\shiwen.cmd add "https://节目网站/feed.xml"
.\shiwen.cmd add "https://节目网站/feed.xml" --episode 1 --summarize

打开文件夹后在空白处右键“在终端中打开”，粘贴命令，把示例路径替换为自己的文件或链接。暂时只转文字时去掉 --summarize，不调用整理模型。RSS 不指定单集时只显示列表，不下载整档。交付版不支持抖音和B站链接；视频平台的网络或登录限制可能影响获取。

④ 看结果与重试

命令结束会打印结果路径，位于本文件夹的 data-core\jobs\任务编号\。transcript.txt 是原稿，summary.md 包含完整整理稿、五段式精华、金句，双击 mindmap.html 打开离线导图。导图打开不再消耗模型费用。

识别人名、数字、专业名词时可能出错；摘要引用与金句可帮助回听定位。默认本地识别，摘要并非完全离线。相同命令重试会复用成功阶段，不重做已完成的转写。完整整理稿暂支持24000字以内，超限不会截断冒充完整。

备份与卸载

完成正在进行的任务后，双击 stop.cmd 停止后台服务，再备份整个 data-core；关闭浏览器本身不会停止后台。双击 uninstall.cmd 卸载本包安装的环境、模型及缓存，默认保留文稿。确认已有备份后，可执行 powershell -NoProfile -ExecutionPolicy Bypass -File .\uninstall.ps1 -RemoveData 连同本包文稿和Key删除。不会删除你原先选取的外部音频，不会卸载系统原有软件。最后可自行删除解压的代码文件夹。

离线准备

可由交付者准备完整的 models 目录，使用 install.ps1 -ModelDir "E:\models" 校验并复制。-Offline 表示禁止联网：除模型外，还需完整预置 .runtime（工具、Python及依赖缓存），缺少时明确报错。普通验收ZIP不附这些大文件；不要把“本地模型模式”误认为“所有安装与AI整理都能离线”。
