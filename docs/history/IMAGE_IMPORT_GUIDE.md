## 以后怎么导入

1. 在图文素材库点“导入图文”。
2. 自用链接选择“分享图文链接（自用）”，粘贴抖音分享文字，点“获取图片并识别”。复用已有独立登录态，只取这一条图集，不采评论/博主、不下载配乐视频。
3. 本地截图选择“图片/截图/多图”，选文件、拖入或粘贴，确认顺序；可以上移和移除，再保留原图并识字。
4. 等待保存和识别，页面显示总张数与进度；缺失/失败会标记。离开页面后服务端任务继续，上传中离开则尚未发送的图片不能自动补齐。

每份1—64张，单图8MB、合计64MB，图文图片库仍为500MB上限。超限不自动扩容、不删除旧资料，不截前24张冒充完整。支持静态PNG/JPEG/WebP/GIF，多帧图片需选单帧。20,000边长/6,000万像素上限由实际解码检查，不能只改后缀。

登录失效/验证时不会绕过，按提示到原登录入口处理；也可以直接保存原图再导入。原生产采集器的代码、定时配置与登录目录未改；本网站继续使用自己的隔离会话。

## 阅读、校对和利用

- 默认先看“完整整理稿”，点一次生成后缓存，可切换“精华”、复制和导出。该稿允许AI改写，不能当逐字原文。
- “原图与识别稿”保留净化阅读和页码切换；点“查看本页原图与区域”展开对照侧栏，窄屏上下排列。全部区域保留，可逐项恢复或排除。筛选/标注不再是阅读的前置步骤。
- “识别存疑”按规则折叠，不代表它是杂讯；展开后可读，也可恢复到正文。AI仅筛选规则判不了的区域，不自动修改任何字。
- 点一段文字，原图标出对应区域；可放大阅读。OCR坐标是图片位置，不是证明这段答案正确。
- “校对”修改该区域的派生文字，保留原始机器识别和原图；人工校对在对照栏单列，不混入净化正文。有版本冲突不覆盖较新校对。未保存校对在本机浏览器暂存，重新打开该区域可恢复。
- 右侧可“提炼学习重点”“整理工具要点”，或自己提问。可选择整份识别稿或当前页，最多2.4万字；超过就选当前页，不偷偷截全文。AI只读提取后的文字，不读图解箭头，也不自动联网核实。
- AI结果保留摘录与材料缺口；点“定位原文”返回引用的图片页。识别稿已改变时会提示旧结果并拒绝错误定位。
- 可把解释加入笔记草稿，再写自己的理解并保存。默认导出净化稿；对照栏可另行导出全部识别稿。笔记和AI说明有单独标题，不作为净化原文，不包含图片文件。

## 加入专题，再找回来

在右侧填写专题名称并“把这份材料加入专题”。转到“专题资料与搜索”，选该专题，搜MCP、缓存、Gist等概念；默认只搜索净化保留区域，可勾选“包含折叠和排除的图片文字”找回其他区域。命中后可查看上下文并打开原图区域位置。文章也可显式加入专题，个人笔记随材料保留。

## AI筛选和人工小样本

“AI筛选疑难区域”只发送待判断区域和有限相邻文字/位置给现有DeepSeek文本模型，不发送原图；结果严格只有区域ID与类别。正文、术语、网址、代码和有实质内容的脚注保留；判断不了默认保留。低置信折叠由规则执行，不付费。结果按输入缓存，失败保留规则及成功批次，不自动重试付费调用。

开发预算按用户授权累计10元；单次按当前供应商高峰价保守预留0.10元，失败调用不释放预留。返回用量估算不等于账单；2026-10-26核对输入2元/百万token、输出8元/百万token。日常文本额度未重置，未加永久日期特例。

“标注与评测”准备200个待确认区域，显示原图红框上下文。人工类别不预填，确认只更新评测标签，不改阅读筛选。可以先标10—20个，不确定可跳过。按页划分调试/留出集，分别对比全部显示、仅规则、规则＋AI；人工阅读覆盖不计入模型成绩。没有足够标签时指标显示样本不足，不宣称准确率。

AI解释不自动混入来源正文；自己的笔记会作为个人记录参与搜索。OCR更正后索引在下次查询核对更新，旧命中不能冒充新位置。K1原来的共享FTS统计风险维持，不在本轮处理。

## 识别组件和边界

实际使用RapidOCR 3.9.2 + PP-OCRv6 small固定ONNX模型，ONNX Runtime 1.23.2、Pillow 12.0.0，CPU4线程。安装在runtime/image-ocr/venv，主应用和原采集器环境没有安装这些新依赖。传递版本锁在requirements-ocr.lock.txt；wheel自带模型经指纹核对，执行识别不自动更换权重。

长图切片有重叠，程序按文字与实际位置去重；同一句出现在不同页或不同位置会保留。依旧可能错字、错序、漏字、读错专名，低评分只提示疑难，不代表准确率。实际发现过切片重复，已修正；截图中状态栏、图解文字和截断的句子也可能进入识别稿。

本轮没有接复杂视觉理解、自动标准题库、模拟面试评分、MCP或LangGraph。图片里说某技术重要，不代表本站已经使用该技术。个人学习场景可继续用原图对照和提问；需核实概念时另查官方资料。

## 私有与公开的边界

private_images.py、extractor.py、PrivateImageCapture.tsx属于自用采集；通用的图片导入/识别/阅读/专题代码不依赖这些模块。核心白名单仍检查禁止词，不带登录态、原图、数据库、OCR环境或模型。未来公开再单独确定发行、依赖许可和安装体验，本轮不发布。
