# 自用图文入口里程碑（2026-10-26）

## 范围和使用

单条分享链接经私有适配器获取有序原图，接入通用图片入口。生产采集器、配置、定时任务和登录目录未改。公开核心只包含本地图片导入、OCR、阅读、校对和专题检索；私有适配器不进入核心包。操作和样本链接见 IMAGE_IMPORT_GUIDE.md，日常入口为原data目录的8765。

## 真实证据

- 面试资料45张、23,600字、1960区域，原图11,178,665字节，逐页OCR耗时合计84.814秒。
- Gist单图459字、24区域，原图266,123字节，OCR耗时1.594秒。
- 时间不含解析、下载和初始化。46张原图哈希均匹配保存记录。
- 现有文本模型真实调用2次：Gist说明3段（8.73秒），面试第14页说明4段（8.19秒）。摘录可在对应OCR稿找到；未调用视觉API，未代写个人笔记。摘录匹配不代表解释语义已验收。
- OCR仍有字词、缩写与顺序误差。58个低分区域不是准确率统计。图解箭头关系未理解，完整性保持未核实。

## 机制和依赖

1—64张、单图8MB、每份64MB、图片库500MB，不自动删除旧资料。缺页占位、重试、结束中断上传保留已存图片。原文与人工修订分开；修订号冲突拒绝覆盖；缓存重跑保留笔记与修订；纯耗时变化不使引用失效。专题只索引明确加入的资料，不索引AI说明。

可选独立环境固定RapidOCR 3.9.2、ONNX Runtime 1.23.2、Pillow 12.0.0，完整锁定见requirements-ocr.lock.txt。模型固定路径及哈希，识别不自动下载替换。主环境和采集器环境未新增依赖。复用文章库、模型、专题和FTS，未引入向量库或新工作流框架。

实际修复：提取脚本切换工作目录后的相对输出路径错误；长图切片重叠产生重复文字。不同页相同内容不做跨页去重。
