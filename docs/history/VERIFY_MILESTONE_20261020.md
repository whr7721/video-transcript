# 命题核实第一版：实现与验收记录

## 范围

选中文稿片段 → 核实这段说法 → 拆出最多三条命题 → 用户核对原话、限定条件及事实/观点分类 → 确认后搜索 → 展示逐条证据关系与来源。只处理确认的命题，不保证覆盖整段所有断言。不会自动修改原稿、编辑稿或专题笔记；保存专题仍需显式操作。

继续复用现有 SQLite research_jobs、单研究工作线程、DeepSeek 搜索/正文抓取、SiliconFlow 文本模型及笔记导出。未增加包、模型或外部接口。UI 延续现有纸白、雾蓝与阅读排版，采用原生复选框和下拉框，先确认再联网。

## 调研与取舍

- [W3C TextQuoteSelector](https://www.w3.org/TR/annotation-model/#text-quote-selector)：借鉴 exact/prefix/suffix 定位，增加片段内偏移；重复句当前取第一次出现。
- [EEA rag-facts-check](https://github.com/eea/rag-facts-check)：参考原子命题与证据片段思路，不引入其运行依赖或复制实现。
- [DeepSeek 官方搜索](https://api-docs.deepseek.com/zh-cn/guides/search/)：沿用原有原问题、质量信号和预算闸；网页正文才可作为引用依据。
- 应用 frontend-design、ui-ux-pro-max 的现有项目适配与交互建议；参考 [Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines) 检查标签、点击区域及原生交互。没有真实浏览器视觉验收。

## 防护与限额

原话必须逐字存在于选段，网页引文必须逐字存在于模型实际读取的前6000字；不采用模糊匹配。缺失证据不能判定为不存在；支持/反驳需要有效引文。第二次模型检查不认可时降级证据不足，检查失败不发布第一遍判定。第二次调用仍为同一模型，不能称独立核实。

确认接口检查任务状态、命题归属、文稿版本、队列长度；重复提交409、跨来源请求403。用户可纠正事实/观点分类，保留模型最初分类。导出包含原话、结论、引文关系及范围提示。

仅按用户授权将北京时间2026-10-20文本调用上限临时从30提高到45；其他日期30。没有清零计数。真实测试后计数43/45；搜索仍每日80次、每月10元估算上限，非实际账单保证。

- 修正后真实复测：`39e23d8fc134e711`，“照做一个月就赚钱”，结果证据不足，无引用；搜索估算0.006元。
- `8f73c55efb347d9c`，PMF相关三条事实，结果证据不足/有支持证据/证据不足。第一条被第二次检查降级；第二条引用同一创业邦文章三段，不是三份独立来源。搜索估算0.018元。原稿和编辑稿前后相同。

尚未完成20条命题的人工证据关系基准，未测真实浏览器操作、移动端和输入法。浏览器工具没有可用页面；外部网页工具无法独立打开创业邦来源，因此仅验证本地保存正文的逐字关系，不能宣称该支持结论已经独立核验。
