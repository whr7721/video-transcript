## 先理解：不是只处理AI学习资料

资料库按来源处理，不按题材限制。你可以导入技术课、历史访谈、播客、旅行攻略、摄影教程、产品说明、读书材料等。音频先转写，文章提取正文，图集先识别文字，之后统一检索。资料里没讲清的事，助手不应靠常识补成“已有依据”。照片本身、图中箭头/关系、视频画面没有在这里被完整理解。

三层数据分开：原文是资料，研究回答是AI产物，个人记忆是你确认保存的记录。个人记忆不等于客观事实或自动推断的个人身份。

## 一次完整使用

1. 在原有工作台导入音视频、RSS、文章或图集，等转写/识别完成。旧资料自动可用，不用重复上传。资料助手首次打开会建立派生索引，随后内容有变化再刷新。
2. 看顶部来源数量，选择全部或音视频、文章、图集、记忆、笔记范围。
3. 先点“本地找资料（免费）”。它不调用模型，适合确定材料是否真的存在。搜不到时试试专有名词、短关键词或另一种语言；当前是中英词法检索，不是向量语义搜索。
4. 选择任务，输入具体问题，再点“让助手研究”。模型自行调用search_library与read_passages，最多4轮，每轮最多3次工具调用，实际读取最多8个800字片段。它没有逐字阅读你的全库。
5. 查看答案、引文和“资料缺口”。展开轨迹可以看助手搜索了什么、读了多少。引用可以打开原资料，但不保证自动高亮准确位置。每节区分资料陈述、推论和行动建议，仍须人工判断。
6. 有用的结果可导出Markdown，或直接送入已接入的卡片排版工具。资料库不是他人内容的公开转载授权，公开发布前需要自己的判断、素材权利与适当标识。

## 四种任务适合什么

| 任务 | 可以这样问 | 重点检查 |
|---|---|---|
| 带依据回答 | “这些资料里，气候与天气有哪些区别？” | 是否确实找到相关资料，引用是否支持整段话 |
| 多资料对比 | “不同访谈对同一个问题有何一致和分歧？” | 是否实际用了多个来源；只有一个来源时不能冒充交叉验证 |
| 学习指南与自测 | “根据摄影课程整理学习顺序，给我自测问题与可查答案。” | 是材料支持的知识，还是模型补充的推论 |
| 行动简报 | “结合操作文稿和我的时间记录，列出下一步与待确认项。” | 建议是建议，不能当作原资料已有结论 |

对于医疗、法律、投资等题材，只把这里当作资料整理与回查工具，不能把检索到的说法当成专业结论。

## 个人记忆

在右侧写标题与内容，点击“保存／更新同名记忆”。可记录项目选择、个人偏好、复盘结论、待办背景；同名会更新，可编辑或移除。研究结果中的“整理为个人记忆草稿”只把内容填入表单，**不会自动保存**。请删去错误或过时的推论再确认。

记忆会进入资料库，可在范围里选择“个人记忆”单独询问。它不是Mem0/Cognee自动抽取系统，也不是知识图谱。编辑/移除记忆后，重新刷新索引；旧研究仍作为历史保存，资料库变动会显示历史状态提示。

## 费用、缓存与恢复

- 免费：导入后的本地索引、检索、手写记忆、查看已保存研究、导出。
- 模型：有界Agent使用现有硅基流动Key。问题与检索命中的片段会发给模型，并非所有数据一直留在本机。原始音频不因这个Agent再次上传。
- 本轮新增20元独立预算账本kb_calls，不清空或抬高旧10元账本。按输入UTF-8字节和输出上界预留，费率采用10/20元每百万token的保守预算政策，**不是供应商报价或账单**。失败且没有usage的预留不返还。
- 所有模型调用仍受原共享每日30次文本调用上限。一个研究通常3至4次，不是一个问题只算一次。
- 问题、模式、资料范围、模型、代码版本与全库指纹相同，读取成功缓存，不再调用模型。资料变化后重新研究会生成新记录。
- 模型失败、超轮数、预算或日限额拒绝会明确报错，不无限重试。服务重启后未完成任务标记失败，需你再次提交。
- 原文与个人笔记不随回答改写；新增表只存派生索引、研究记录、明确记忆与调用账本。

## 本轮验证与限制

共6次真实研究尝试、19次模型调用。隔离库包含用户现有16份音视频文稿、4份文章、2份图集，再加入1份NOAA公开科普文本和1条标明“非真实用户偏好”的摄影记忆夹具。公开文本与夹具只在runtime，未写进日常资料库。日常账本保留真实费用调用，没有清零。

| 场景 | 实测表现 |
|---|---|
| Agent上下文/记忆比较 | 19.562秒，搜索改写、读取3段，保留6节回答；初版存在从OCR图示文字推断布局的倾向，已收紧提示，不能宣称图解理解通过 |
| NOAA科普问答 | 10.562秒，读1段，3节回答；最终版本复测12.985秒，区分资料陈述、推论、建议，共6节 |
| 摄影学习记忆夹具 | 14.188秒，识别为测试记录而非真实用户偏好，建议明确标为推导 |
| 限定音频的小程序操作简报 | 26.141秒，读6段，只使用audio范围，保留8节，1处引用不合格被移除 |
| 不存在的ZXQ-9182实验 | 20.281秒，精确编号检索无命中；模型仍尝试输出无有效引用内容，7处被校验移除，最终无回答并列缺口。因此拒答是系统校验发挥作用，不能说模型从不幻觉 |

累计预留4.34元，按保守政策的usage估算0.78752元；20元上限未达到。账号实际消耗以硅基流动后台为准，没有花完额度来凑测试。

引文逐字匹配只验证文字存在。选段不完整、OCR错误、来源本身不可靠、推论过度都仍可能发生。这些小样本不是准确率评测，也不能推出“全库理解正确率”。真实GUI、中文输入、浏览器导出与卡片效果仍待用户点验。
