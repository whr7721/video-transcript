## 2. A 类：卖成品和服务（最快见钱，你现在就能做）

### A1 卖资料包 —— 建议第一优先

你手里已经有现成商品：45 图 Agent 面试资料 → 9916 字整理稿 + 658 字精华。这就是"AI 面试八股精编"的样章。

- 渠道：闲鱼（上架快、有自然流量）、小红书（发"Agent 面试高频考点"图文引流）。
- 定价：9.9–29.9 元/份，面试季（秋招补录、春招）需求真实。
- 启动：今天就能上架。样章放前 3 章，全文网盘交付。
- **版权红线（这条决定你会不会被投诉下架）**：卖"自己重新组织的笔记+标注来源"，不要卖"某博主视频的文字版"。前者是你的整理成果，后者是侵权，博主一投诉就下架。你现有的整理稿已经是"合并同主题、去界面杂讯"的重组，达线，但交付物里要写"整理自公开分享内容，版权归原作者"。
- 风险：闲鱼对虚拟商品会误伤下架，多账号多链接对冲即可，无法律风险。

### A2 代整理服务

别人发你视频/图集链接，你跑本地链路出整理稿，按份收钱。

- 渠道：朋友圈、考研群、牛客/即刻、小红书私信。
- 定价：9.9–29.9/份（视频），图集 19.9（多图贵是合理的，你的实测成本 0.28 元，毛利够）。
- 风险定价：你处理链接用的是 MediaCrawler（许可证禁止商用）。私下小规模违约，对方发现+举证+觉得值得起诉的概率≈0。**违约但不被追责 ≠ 合规**，这条你自己判断。版权层面：整理稿给个人自用，风险与 A1 相同且更低。
- 这条的价值：验证定价和需求，攒真实用户反馈，为 B1 铺路。

### A3 卖经历

"天大 AI 学生，一个人从 0 到 1 做了个 AI 产品并真实收到钱"——这个叙事对学弟学妹值钱，比工具本身值钱。

- 形态：项目辅导 1v1（99–299/小时）、小课（99–399）、简历项目包装（199–499）。
- 渠道：B站发build过程、知乎写复盘、小红书发"普通人怎么做 AI 项目"。
- 风险：白。唯一要求：别吹没做到的事（你项目文档里自己写过这条纪律）。

## 4. C 类：灰色（能做，先看清价格）

### C1 轻抖模式 —— 最多人问的一条，风险算清楚

做法：自研最小解析（Playwright 自己写逻辑，删掉 MediaCrawler import），类目挂"工具"，页面放"免费+免责+用户自担"话术，会员卖时长，广告做闸门。

风险定价（这是这条路径的真实价格，不是吓唬）：

1. **民事判赔有先例**。视频平台起诉去水印/解析工具的不正当竞争案公开判例多起（自行检索"抖音 去水印 不正当竞争 判决""视频解析 不正当竞争 赔偿"），判赔为百万量级。轻抖活着的真相不是"合法"，是"值得被起诉的成本收益比"——它是矩阵，死一个还有九个；你是单兵。
2. **个人主体 = 无限责任**。公司被诉赔的是公司的钱，个人被诉赔的是你的全部财产，还上征信。这是 C 类所有路径的共同底价。
3. **封主体连带**。微信对违规小程序的处置会连主体，个人主体被封后这个身份证基本不能再做小程序，你后面所有 B 类路径一起报废。
4. 时点问题：你正处于"违约成本最高的时期"——学生身份、以后要落户/考编/背调，一个民事判决或失信记录跟着你十年。

结论：C1 不是不能做，是**做了就别当事业，当一次性现金流**，且要在你有其他主体、其他收入之后再碰。现在碰，赌注是整个未来换月入几千。

### C2 矩阵号引流 —— 风险最低的灰，建议用

小红书/抖音发"我把XX视频整理成了一篇文章"的对比图，评论区/主页导流微信。这是放大器，给 A1/A2/B1 供流量。
风险：平台封号（小红书对导流极敏感），无法律风险。对冲：一机多号、内容为主私域为辅、别在正文留联系方式。封一个号损失的是号不是人。

### C3 借身份证矩阵 —— 不值

个人主体小程序注册数量有限（以官方当期规则为准），借同学身份证注册违反微信实名制，被识别连带全封，还欠人情。轻抖的矩阵是企业多主体，你复刻不了。

### C4 Key 倒卖 —— 不碰

硅基流动 Key 转售违反 ToS，封 Key 即归零；买家拿去做什么你不可控，出事时"你提供的接口"出现在链条里，量大有非法经营/帮信的入罪先例。时薪算下来不如 A2。

## 5. D 类：刑事区（明确列出来，但期望值为负）

D1 爬抖音数据卖：登录态+绕风控批量抓取并出售，涉及"非法获取计算机信息系统数据"（刑法285条），有真实判例，且这个市场上职业团队有设备农场和账号池，你单兵技术又不占优——**风险最高的路径恰好是你竞争力最弱的路径**。
D2 卖 Key 给不明买家：帮信罪风险，单价低，不可控。

这两条不是道德问题，是数学问题：下行无限（刑期+案底），上行有限（个人灰产天花板远低于你的想象），期望值为负。

## 6. 三个你没想到的事实（比路径清单重要）

**事实一：你真正的独家资产不是工具，是"天大 AI 学生 + 真实项目 + 离用户近"。**
工具维度你打不过轻抖（它 98 个页面、企业矩阵、法务话术）。但"Agent 面试怎么准备"这个问题，学弟学妹信你，不信轻抖。卖工具给陌生人是最慢的路径，卖判断给信任你的人是最快的。

**事实二：灰产真正赚钱的是分发，不是技术。**
你没有分发。职业灰产团队有账号池、设备农场、投流预算。单兵进灰产是炮灰量级——收入天花板低、归零概率高、还是刑事区的主要居民。你能竞争的分发渠道恰好是"内容+信任"（B站/小红书/校园），那条路是白的。

**事实三：你现在就有现成商品，不需要先上线。**
45 图→9916 字整理稿就是商品本体。变现的第一步不是"部署服务器"，是"今天在闲鱼上架"。备案、小程序、支付那一整套是第二阶段的资产建设，跟第一笔收入不冲突、不互相等待。
