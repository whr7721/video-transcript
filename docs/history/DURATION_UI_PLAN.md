# 批量时长设置与界面调整

用户指定默认10分钟，增加20/30分钟。继续复用现有模型、MediaCrawler和原生HTML，不新增组件依赖。

调研：GOV.UK radios（https://design-system.service.gov.uk/components/radios/）提供fieldset/legend、标签及简短提示的成熟模式；Carbon可选择tile（https://www.carbondesignsystem.com/building-blocks/core/components/tile/guidelines）提供整块可点的单选模式。参考交互方式，自写局部样式，不复制品牌素材或引入框架。GOV.UK默认不预选的通用建议由用户明确指定默认10分钟覆盖。原生控件无需新依赖、许可证或包维护成本。

视觉：沿用纸白#ffffff、雾蓝#f6f8fc、文字#17243b、强调蓝#2855d9、分隔线#e3e8f1。Segoe UI/微软雅黑负责控件，文稿字体不变。布局左对齐，批量配置上行为数量，下行为10/20/30单选，再下方媒体保留。时长只用一组紧凑整块单选，不扩散为大量装饰卡片；默认标记、勾选态和键盘焦点都明确。小屏自动换行。复查后保留现有品牌，不引入与任务无关的视觉装饰。

实施：参数贯穿API、主页筛选、抓取停止条件、实际媒体时长复核；旧批次缺省600秒；页面实时说明新任务范围并显示历史批次真实设置。验证三档边界、参数拒绝、旧批次兼容、前后端语法、现有测试；使用真实10—20分钟素材验证，30分钟在未真实验证前明确标注。浏览器通道若可用则截图/交互验收。
