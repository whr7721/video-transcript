## 交付与装配

- `app_shared.py` 共享安全中间件、编辑/研究/文章路由及恢复；`app_core.py` 为独立进程入口，`app.py` 继续私有来源能力。平台模块仍保留原文件位置以降低旧路径兼容风险，但只由私有装配引用，公开包完全排除。
- `source_contract.py` 固定本地来源 schema_version 1、名称/内容哈希/字节数及显式处理器注册。旧任务在私有调度中按旧字段解释，不写回迁移；核心暂不注册文件处理器、不恢复未知任务，也不接受分享链接提交。
- `media_io.py` 共享现有 FFmpeg 准备阶段，`transcript_stage.py` 共享 ASR、进度与转写导出。私有管线使用这两个模块。本地来源可以不携带 source_url，Markdown 使用原文件名作为来源。
- `Studio.tsx` 为单一共享编辑器，通过 `SourceUI` 注入来源表单/导航/链接；`private-source-ui.tsx` 仅私有入口引用，`frontend/core` 独立构建。不是保留静态 import 后运行时隐藏。
- 核心使用独立 `data-core`，设置/数据库随其隔离；入口拒绝未标记的非空目录和同进程混装。不修改原 `data`。核心 UI 如实显示文件入口尚未开放。
- `build_core_package.py` 内部白名单生成包，公共源码、预编译前端、依赖锁和专用 README/启动脚本共 49 个文件；不复制 .git、历史页面、平台文件、数据、模型、配置凭据、node_modules 或内部审查/研究文档。验证器本身留在内部仓库。
- 无新增外部依赖、模型或 API；没有付费调用、平台爬取、模型下载。GitHub 保持私有，未发布仓库或网站。
