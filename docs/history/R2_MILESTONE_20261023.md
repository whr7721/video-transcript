## 用户现在可以做什么

在原稿页打开“章节与导读” → 先看预算再生成 → 预览并采用目录 → 选章阅读原话/独立整理 → 选择原话研究并留专题笔记 → 导出目录/整理预览或笔记。所有生成产物与原稿/编辑稿分离，完整稿旧24000字限制保持原样。

目录可改名、按原文片段拆分、合并相邻章节；范围变更追加新版本，不重排或删除正文，拆并清除对应旧导读。章节笔记持有旧版本、原稿hash、源段及偏移，重新分章不改旧笔记。Unicode选区按码点处理，补充平面字符不会导致重复句定位偏移。

机器回查只证明文字位置，不保证语义支持。模型改写的引用不展示为原话：位置合法时以程序提取的原文为location_only参考并标review_required，非法/歧义位置拒绝。导读、回查及整理疑词可见，模型自评不作为验收。
