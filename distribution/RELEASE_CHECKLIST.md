# 候选发行与公开发布检查清单

代码实现、作者自测、独立审查、用户验收与公众发布分别记录，不能互相替代。

## 每次候选构建

- [ ] 固定源码commit，工作区干净；若为脏工作区仅标开发候选。
- [ ] Python/Node/npm/Vite/zlib版本与锁文件摘要有记录；新增依赖和许可已核对。
- [ ] 前后端回归及核心/私有构建成功；真实元数据/文字/音频路径和失败样本有记录。
- [ ] README支持边界、路线图、已知限制和待验收项与实际版本一致。
- [ ] 仅从白名单构建；不带凭据、模型、用户素材、运行数据、依赖目录或.git。
- [ ] 全目录路径/全字节扫描及解压后复扫通过，禁止内容门保持有效。
- [ ] manifest精确列出除自身之外的全部文件；逐文件hash符合，缺文件/多文件/同长度改字节/截断均能拒绝。
- [ ] 固定ZIP时间戳、权限、顺序与压缩配置；两个独立暂存的同输入产物逐字节一致。
- [ ] 最后计算ZIP SHA256，生成包外SHA256SUMS.txt与release-metadata.json，之后不再改ZIP。
- [ ] 交付时ZIP、checksum和metadata来自同一构建；校验值另与可信交付记录核对。

## 公众发布前仍须独立确认

- [ ] 已收到独立缺陷审查结论，必修项已清。
- [ ] R2章节目录/导读/拆并/原话选区/按章整理人工点验；三条真实长稿和短稿对照的质量检查有记录。
- [ ] 官方章节真实节目映射验证，或明确标为尚未实测，不用夹具替代。
- [ ] 新RSS界面人工点验，包括中文输入、错误状态、取消和打开稿件。
- [ ] 独立Windows电脑仅按README完整部署，有人工协助记录。
- [ ] 独立无代理机器从空模型目录真实下载，固定校验通过。
- [ ] 长素材头中尾及术语人工听校，有差错记录。
- [ ] 自身代码、模型、第三方及内容来源使用条件已核对；确定对外许可。
- [ ] 公开仓库使用审过的干净产物与新历史，不公开内部历史或直接附整仓库source archive。
- [ ] 用户明确授权正式发布及其目标位置，确定签名/可信校验值发布渠道。

本模板的未勾选项不代表通过。具体本轮通过/未通过的证据由内部里程碑和release记录提供；生成一个hash不会自动完成其余验收。
