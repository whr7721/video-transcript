# 拾文 · 本地内容工作台（V1-A 核心隔离预览）

目标环境：Windows 10/11、Python 3.11 x64、FFmpeg。当前交付用于核心隔离验收，本地音视频文件导入尚未开放；随后阶段才完成上传、转写、长音频压力和独立部署验收。不要把本预览当成最终安装包。

已包含共享编辑器、文章导入、正文阅读、选段研究、专题笔记及导出。模型及搜索需要自行配置 Key 才可调用；未配置可阅读、手动编辑。所有网络操作由你主动触发。

## 启动

在解压目录运行 PowerShell：

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock.txt
.\start-core.ps1
```

访问 http://127.0.0.1:8766/studio/ 。前端已编译，无需 Node；若要修改前端，进入 frontend 执行 `npm ci`、`npm run build`。后端入口 `app_core:app`；请每个入口独立启动进程。仅监听本机，不直接暴露公网。

## 数据与边界

数据默认保存至解压目录的 `data-core`。可在启动前设置 `SHIWEN_CORE_DATA_DIR` 为另一个独立目录。不要指向其他应用的数据目录。清空或重新解压程序不会自动迁移用户数据，请自行备份。

本版本没有可用的文件任务处理器，也不会恢复或改写未知来源的待处理任务。5GB 媒体缓冲政策保留，实际长音频配额压力测试在文件入口阶段进行；模型自动下载及无代理下载实测在独立部署阶段进行。本包不包含模型、用户素材、配置密钥、运行数据、历史仓库或开发依赖目录。

模型下载工具尚未交付，因此缺少模型时 health 会如实显示未就绪；这不影响核心启动与文章功能。完整本地转写要等待后续阶段完成，不能以本次启动成功代替最终功能验收。

前端采用 React、Tiptap、Radix、Tailwind 等，后端采用 FastAPI、SQLite 及现有文本/语音处理依赖；具体版本见两个 lock 文件。本预览为本地交付，尚未对外发布。
