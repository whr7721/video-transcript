# 拾文

本机运行的内容工作台：抖音转写保留原话，编辑工作台按需生成整理稿与研究结果。识别可能出错，不能可靠找出全部错误；AI结果不等同人工核实。

## 本地文件核心候选包（V1-D）

可分享核心使用独立入口 `app_core:app` 与独立数据目录，不需要本仓库的私有来源工具。公开包部署说明见 [distribution/README.md](distribution/README.md)，测试记录表见 [DEPLOYMENT_ACCEPTANCE.md](distribution/DEPLOYMENT_ACCEPTANCE.md)。不要直接把整个私有仓库或历史公开。

在已构建核心前端后运行 `.venv/Scripts/python.exe build_core_package.py`，生成白名单 ZIP，附预编译工作台、固定版本模型准备器、环境检查和第三方通知；不附模型或运行数据。独立 Windows 与无代理机器部署由外部测试者实测，暂时缺少环境，不能据本机演练宣布最终通过。以下旧段落记录私有入口及其历史能力，不作为核心包安装步骤。

## 设置与登录

默认本地 SenseVoice INT8（sherpa-onnx），音频不发送到第三方。设置可选硅基流动 SenseVoiceSmall；用户尚未提供 Key，云端链路尚未真实验证。只接入该免费模型，未开放付费模型选择；当前价格与实际额度以供应商账号为准。

Key 可在网页设置输入，使用当前 Windows 用户 DPAPI 加密保存在 data/settings.json，也可由 SILICONFLOW_API_KEY 环境变量提供。网页读取设置时不返回 Key。不要提交 data/ 到版本库。

抖音使用独立浏览器目录 data/browser。首次使用时，从原 MediaCrawler 复制必要会话文件，且只在原 Chromium 未占用源 profile 时进行。之后不打开、修改原 profile。会话失效时，在设置点击“打开登录窗口”，在独立浏览器扫码，完成后关闭整个窗口，再提取。登录窗口最多保留约 10 分钟。不会自动解决验证码；若抖音要求人工验证，需要用户在独立窗口自行操作。

项目只读使用 D:/zcode1/mediacrawler 的既有 Python 和单作品客户端，不调用其 main.py，不改变其配置、定时任务或数据文件。此依赖不可随意移动；旧项目的依赖更新可能影响采集适配。

## 文件与恢复

- data/tasks.sqlite3：任务历史与状态。
- data/jobs/<任务 ID>/original.mp4：保留的原视频。
- audio.wav：识别用单声道 16 kHz 音频。
- local_chunks/、cloud_chunks/：逐段结果，重试复用已完成内容。
- source.json：来源详情与可过期直链，不向网页透传原始对象。
- transcript.txt / .md / .json：最终结果。
- models/：只下载一次的官方识别模型。

重复相同链接和识别方式会打开已有任务，不重复识别。不同的分享短链可能仍对应同一作品，跨短链的作品去重目前尚未实现。失败任务点击重试；程序重启自动继续原队列。网络中断下载会重新下载该视频，转写恢复粒度为已落盘语音段。不会删除用户原有文件；任务媒体按下文5GB缓冲规则管理。

云端片段时间仅代表上传边界；本地时间是 VAD 语音段边界。首版不导出精准 SRT，也不把片段时间冒充词级对齐。

## 开发与复现

Python 3.11、FFmpeg、Windows。独立环境：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock.txt
.\.venv\Scripts\python.exe -X utf8 setup_models.py
.\.venv\Scripts\python.exe -X utf8 -m uvicorn app:app --host 127.0.0.1 --port 8765
```

模型下载使用本机 7890 代理；抖音页面、媒体下载与硅基流动 HTTP 客户端显式不继承系统代理。无须安装 CUDA、PyTorch 或 yt-dlp。要换电脑使用，需重新配置 MediaCrawler 路径和登录态，不能把这里的会话文件公开分发。

命令行也可用：

```powershell
.\.venv\Scripts\python.exe -X utf8 cli.py 'https://v.douyin.com/Dv4LnzQVp8E/'
.\.venv\Scripts\python.exe -X utf8 -m unittest discover -s tests -v
```

网页采用 Sites 的本地静态实现/预览方式，与本机 FastAPI 同源服务，没有创建或部署线上 Site。云端 Sites Workers 无法直接使用本机 profile 和文件；以后若需在线访问，应另行设计授权和本地任务连接，不能直接上传本项目 data/。

## 博主批量（2026-10-19）

在提取方式中选择“博主批量”，粘贴抖音主页或该作者的任意一条作品分享文字。程序读取真实作者编号，按平台返回顺序（含置顶）获取作品；可选10/20/30分钟以内，默认10分钟；列表筛选和下载后的实际时长复核使用同一设置。首次建议10条，可选30/100条。批次结束后“再获取10条”扩大当前批次，可继续分页获取；累计10000条为保护上限，不是自动无限采集。

主页分页和作品列表保存在本项目 data/batches，失败重试复用分页进度。按作品ID和识别方式复用已有任务及文稿。批次显示已发现、跳过、成功、失败、待处理数量；“本批结束”不代表“博主所有作品已获取”。

暂停只暂停后续排队，正在处理的一条会先完成；继续恢复排队。批次结束后可重试失败条目，下载ZIP含已完成TXT/Markdown和批次索引，索引保留失败及未获取情况。

批量和单条统一使用5GB媒体缓冲。转写完成后保留至最终稿确认；空间不足优先清理已确认、未固定且未播放占用的素材，否则暂停新下载。历史已被旧规则删除的媒体不能自动恢复。

直接调用现有 MediaCrawler 虚拟环境及分页客户端，无需安装第二套爬虫或MCP；只使用本工具独立浏览器会话，不写生产爬虫配置、数据和定时任务。

批次创建后保留本次时长设置，继续获取沿用本批设置；新建批次默认10分钟。旧批次缺少设置时按10分钟处理。30分钟档已做边界和参数检查，真实长素材需单独验证。


## 编辑工作台（2026-10-19）

启动本地服务后访问 http://127.0.0.1:8765/studio/ 。原转写/批量管理入口仍为 `/`，可互相跳转。新版复用React、Tiptap、shadcn/Radix、Lucide、Resizable Panels与jsdiff，依赖版本锁定于frontend/package-lock.json。

首次搭建或前端改动后，在frontend目录运行`npm ci`、`npm run build`；运行时由FastAPI直接提供静态构建，不额外启动Node后台。前端测试`npm test`，后端测试`.venv/Scripts/python.exe -m unittest discover -s tests -v`。

已有完成任务可直接打开编辑稿。支持标题/加粗/列表/引用、撤销重做、自动保存、浏览器草稿恢复、历史版本、Ctrl/Cmd+S、原稿对照与段级回听。识别原稿不覆盖；确认最终稿是用户主动操作。Markdown由编辑器的Markdown模块导出，TXT/JSON由服务端保存版本导出。

整理段落是本地操作，不调用模型；摘要和金句按需调用用户选定的硅基流动deepseek-ai/DeepSeek-V4.1-Flash（按平台计费，无法确认1017快照），每日本工具限制30次模型请求。长稿按来源段分块，请求数不等于点击次数。结果先预览，用户主动加入稿件；原文摘录必须匹配识别原稿，识别原稿本身仍可能有错。生成期间继续编辑会使旧结果无法直接采用，需保存后重新生成。

媒体规则已改为5GB缓冲：新任务转写后保留媒体直到用户确认最终稿；达到上限先清理已确认且未固定、未播放占用的素材，不够则进入等待空间。正在编辑/回听、待确认和固定保留素材受保护。编辑页左下角可清理已确认素材并继续排队；来源面板可固定保留媒体。已保存文稿、修订与原始识别结果不参与媒体清理。历史已删除音频不会自动恢复。已知历史任务剩余媒体只登记为待确认，不删除。

视觉方向沿用纸白/雾蓝的中文编辑工作台。当前自动浏览器通道无法接入本地标签，因此未完成截图、真实输入法与移动端的可视化验收；组件测试覆盖挂载、自动保存与结果不自动覆盖文稿。

## 选段研究与专题笔记（2026-10-20）

在文稿中选中文字，点击“深入一下”，可解释概念、寻找案例或寻找局限。默认非联网解释会明确标注未核实；案例与局限使用联网路径。设置中分别保存硅基流动文本 Key 和 DeepSeek 官方搜索 Key，后者用于官方 Search/Fetch，不共用优惠券或密钥。密钥在本机使用 DPAPI 加密，接口仅返回是否配置。

研究结果与文稿分开，包含来源链接、正文摘录和待核实事项。引文先做原文匹配，再由模型复核支持关系；“AI已复核”不等于人工核实。用户可将结果保存到专题、补充自己的理解并导出 Markdown。不会自动改写原稿或编辑稿。

单次最多3个搜索查询、5篇正文；缓存24小时，支持取消与显式重试。搜索工具每天最多80次尝试、每月估算预算10元；工具用量按保守单次估算控制，不代替平台实际账单。文本调用沿用每日30次限制。
